# Course Management System

This is a university course registration system built using **Node.js, Express, MongoDB, and JavaScript**.

## 📂 Repository Link
[CourseManagementSystem](https://github.com/AbbasHafeez/CourseManagementSystem)

## 📌 Features
- Student and admin login
- Course registration and seat availability
- Schedule conflict detection
- Real-time seat updates

## 🛠 Technologies Used
- **Backend**: Node.js, Express, MongoDB  
- **Frontend**: HTML, CSS, JavaScript  

## 🚀 How to Run
1. Clone the repo:  
   ```bash
   git clone https://github.com/AbbasHafeez/CourseManagementSystem.git
   ```
   
2. Install dependencies:  
   ```bash
   npm install
   ```

3. Start the server:  
   ```bash
   node server.js
   ```
